# Pickle Party

把 LINE 群組的接龍訊息貼進來，自動抓出名字，選單打或雙打、場地數，就排好整場賽程，打球時直接在手機上記分。

## 功能

- **貼上接龍自動解析**：一鍵「貼上剛剛複製的接龍」（或長按輸入框貼上）；支援 `1.名字`、`1 名字`、`1、名字`、全形數字；空位、「滿額」會略過；`民16:15` 會辨識成 16:15 才到；`小明+1` 會多加一位「小明+1」；同名的人會標「同名？」；「候補」之後的人預設不排。
- **排賽程**：一輪 = 每個人都和其他每個人搭檔（單打：對打）過一次；設定頁會說這一輪幾場、大約多久；休息平均、不連打三場以上（人太少或有人晚到做不到時會說明）；晚到的人從第 3 場開始排。人多時在背景排，畫面不會卡住。
- **記分**：每隊的分數是一顆大按鈕（下面寫「✎ 點這裡記分」），點了直接選分數；按「這場打完了」後 8 秒內可以「復原」；兩隊都沒到 11 分時會再確認一次。「現在」的名字用不影響版面的最大字級（依手機寬度），太長的名字自動縮小。
- **換場**：每面球場各自往下打；「有人還沒到？換一場」可以選那個人，改打後面一場沒有他的比賽；球場空著、場邊有人時，可以「先讓場邊的人打」（賽程裡有現成的就提前，沒有就加打一場）。
- **排名**：勝率 → 每場平均淨勝分 → 得分多 → 失分少；成績一樣名次相同。
- **中途有人加入或離開**：保留已開打的比賽，其他的依新名單重排。
- **多人即時同步**：「現在」頁下方「複製觀看連結」貼到群組（只能看）；右上角「⋯」也可以分享「記分」連結給幫忙記分的人（可以改比分）。不用註冊；兩面球場各自記分不會互相覆蓋；離線時記的分數連上網路後會自動補送。
- **長輩友善**：字至少 16px、對比 4.5:1 以上、按鈕至少 48px；可在選單切換亮色／暗色。打開 app 會直接回到今天還沒打完的球局；手機返回鍵會回到上一個畫面。
- **可安裝到手機主畫面（PWA）**，沒網路也能用；記分時螢幕不會自動鎖。

## 雲端同步（Firebase）

- 使用 Firebase Realtime Database + 匿名登入，設定在 `js/firebase-config.js`（公開資訊，不是密碼）。把它設成 `null` 就會變回純本機版。
- 權限由 `database.rules.json` 控管，修改後要到 Firebase 主控台 → Realtime Database → 規則 貼上並發布：
  - `events/{id}`：有 id 的人都能讀；只有登記在 `editors/{id}` 的人能寫。
  - `secrets/{id}/editKey`：沒有人能讀，只能在建立時寫一次。
  - `editors/{id}/{uid}`：寫入值必須等於編輯密鑰，才算拿到記分權限。
- 記分連結 `#j={id}~{editKey}`、觀看連結 `#w={id}`。

## 本機開發

```bash
node tools/serve.mjs        # http://localhost:5173
node --test test/*.test.mjs # 跑測試
node tools/make-icons.mjs   # 重新產生 PNG 圖示
```

純靜態網頁，沒有建置步驟，也沒有任何相依套件。

## 部署

推到 GitHub 後，`.github/workflows/pages.yml` 會自動跑測試並部署到 GitHub Pages。
第一次要在 repo 的 **Settings → Pages → Source** 選 **GitHub Actions**。
